# PDF Scanner

A Windows desktop app that fuzzy-searches a folder of PDFs for a keyword, lists every hit
grouped by file and page, and lets you inspect the match either in a built-in PDF.js viewer
(with the hit highlighted) or in Adobe Acrobat Reader on the right page.

The app was **reworked from Electron + Python to Go + Wails v2**.
There is no Python and no Electron in this repository any more — if you still have a
WinPython folder or `dist-electron/` lying around from an older checkout, they are dead
weight.

> **Status:** the Go rework compiles and runs, but it is not at feature parity with the old
> Python build. Highlight positions are approximated, drag & drop upload is broken, and
> several errors are silently swallowed. See [To-Do.md](To-Do.md) for the full list.

## Architecture

```
main.go              Wails app bootstrap; embeds frontend/dist, binds *App
app.go               Bound API surface (the methods the frontend can call)
internal/search/     PDF text extraction + fuzzy matching (MuPDF via go-fitz)
internal/opener/     Launches Adobe Acrobat Reader at a given page
frontend/            Vue 3 + Vite SPA (JS with `script setup`, TS only for entry/config)
frontend/wailsjs/    GENERATED by the Wails CLI — not committed, see "Building"
```

Frontend ⇄ backend uses Wails bindings (generated JS wrappers over Go methods) plus one
Wails event, `search-progress`, for progress ticks and the final result payload.

### Bound Go API (`app.go`)

| Method | Signature | Purpose |
| --- | --- | --- |
| `LoadSettings` | `() Settings` | Read `settings.json`, fill defaults |
| `SaveSettings` | `(Settings) error` | Non-destructive merge back to disk |
| `GetPDFsFolder` | `() string` | The folder that gets searched |
| `SearchPDFs` | `(folder, keyword string) []SearchResult` | Runs the search, emits `search-progress` |
| `OpenPDF` | `(path string, page int) error` | Opens the file in Acrobat at `page` |
| `LoadPDF` | `(path string) []byte` | Raw bytes for the in-app PDF.js viewer |
| `SelectFiles` | `() []string` | Native multi-select dialog, `*.pdf` filter |
| `MoveFileToPDFsFolder` | `(src string) error` | Copies `src` into the PDFs folder |

### Settings file

Stored at `%AppData%\pdf-searcher\settings.json` (`os.UserConfigDir()`):

```json
{
  "theme": "light",
  "language": "de",
  "searchHistory": [{ "timestamp": "21.8. 22:28", "keyword": "..." }],
  "highlightColor": "#9B59B6",
  "pdfsFolder": "C:\\Users\\<you>\\Documents\\PDFs"
}
```

`theme` and `language` are persisted but **not read by the UI** — the theme actually lives in
`localStorage`, and every string is hardcoded German. `pdfsFolder` has no UI to change it.

## How the search works (`internal/search/search.go`)

1. `filepath.Walk` collects every `*.pdf` under the configured folder (recursive).
2. One goroutine per file — **unbounded**, no worker pool.
3. Per page: `doc.Text(page)` for the plain text, `doc.HTML(page, false)` for coordinates.
4. Each text line is scored by `advancedMatch`, a five-strategy cascade:

   | # | Strategy | Confidence |
   | --- | --- | --- |
   | 1 | Case-insensitive substring | 100 |
   | 2 | Normalised scientific name (`E. coli` ≡ `e.coli`) | 95 |
   | 3 | Token equality after normalisation | 90 |
   | 4 | Levenshtein ratio / partial ratio (go-edlib) | computed |
   | 5 | Character 3-gram Jaccard similarity | computed |

5. Lines scoring **< 85 are dropped**; survivors are deduped per `(page, foundWord)`.
6. Match rectangles are derived by regex-parsing MuPDF's absolutely-positioned HTML output
   and **estimating character width as `fontSize × 0.5`**. This is an approximation, not a
   real glyph box — highlights drift on the x-axis, badly for non-monospace or wide glyphs.
7. Results are sorted by confidence descending and returned in one `search-progress` event.

## Prerequisites

- **Windows 10/11** (the Acrobat opener and the default paths are Windows-only)
- **Go 1.26.1+** (`go.mod` pins `go 1.26.1`)
- **A C toolchain** — `go-fitz` is cgo. MSYS2/mingw-w64 `gcc` on `PATH` works.
- **Node.js 20+** and npm
- **Wails CLI v2**: `go install github.com/wailsapp/wails/v2/cmd/wails@latest`
- **WebView2 runtime** (preinstalled on Windows 11; `wails doctor` will tell you)
- **Adobe Acrobat Reader** — optional, only for the "öffnen" button. Without it that button
  errors; the in-app viewer still works.

## Building

**You must use the Wails CLI.** `go build ./...` and `npm run build` both fail on a clean
checkout, by design of the Wails toolchain:

- `go build ./...` → `pattern all:frontend/dist: no matching files found`
  (the frontend has not been built yet)
- `npm run build` → `Could not resolve "../wailsjs/go/main/App"`
  (bindings under `frontend/wailsjs/` are generated by the Wails CLI, and are not committed)

`wails dev` / `wails build` generate the bindings first, then run the frontend build, then
compile Go — so they work.

```sh
# one-time
go install github.com/wailsapp/wails/v2/cmd/wails@latest
wails doctor            # verify gcc, Node, WebView2

# live-reload development (Vue HMR + Go rebuild)
wails dev

# production binary -> build/bin/PDF-Searcher.exe
wails build
```

If you only want to type-check or lint the Go side without the frontend, build the packages
directly — these do work on a clean checkout:

```sh
go build ./internal/...
go vet ./internal/...
```

## Using it

1. Launch the app. It searches `%USERPROFILE%\Documents\PDFs` by default — create that
   folder or the search silently returns nothing.
2. **📄 Neue PDF-Datei hinzufügen** → click the drop area to pick files via the native
   dialog. (Dragging files onto it does *not* work — see To-Do.)
3. Type a keyword, hit **🔍 Suchen**. A progress bar tracks completed files.
4. Results are grouped per file; click a filename to expand its pages.
5. Click a page entry to render it in the embedded viewer with the match highlighted;
   click **öffnen** to open it in Acrobat at that page instead.
6. The ⚙️ sidebar holds the light/dark toggle and the search history (max 23 entries,
   click one to reuse the keyword). The highlight colour picker sits under the viewer.

## Tech stack

| Layer | Choice |
| --- | --- |
| Shell | [Wails v2](https://wails.io/) 2.12.0 |
| Backend | Go 1.26.1 |
| PDF text/HTML extraction | [go-fitz](https://github.com/gen2brain/go-fitz) 1.24.15 (MuPDF, cgo) |
